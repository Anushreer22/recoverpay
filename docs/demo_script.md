# RecoverPay demo (ASI:One)

Nothing in this demo is legal advice. Drafts stay unsent.

1. Start the four agents from the repo root (`python -m agents.<name>.agent`).
2. Connect the orchestrator mailbox in the Agentverse inspector.
3. In ASI:One, open the orchestrator and send `hello`.
4. Complete the registration card: Udyam yes, class small, activity manufacturing.
5. Load **Case 1 — clean match**. Point at the interest line labelled `estimate, verify` and the unsent reminder draft.
6. Send `reset`. Repeat eligibility, then load **Case 2** (PO mismatch flags) and **Case 3** (no delivery proof → document request only, no payment-reminder claim).
7. Say that RecoverPay never files on Samadhaan and never sends the buyer email.
